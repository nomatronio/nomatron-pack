# nomatron-pack

Official [Nomad Pack](https://developer.hashicorp.com/nomad/tools/nomad-pack) for deploying [Nomatron](https://nomatron.io) on HashiCorp Nomad.

The pack lives in the [`nomatron/`](nomatron/) directory. **Start here:** [nomatron/README.md](nomatron/README.md).

**Maintainers:** [CONTRIBUTING.md](CONTRIBUTING.md) — development workflow, community registry sync on `v*` tags, publishing guide.

**License:** [Mozilla Public License 2.0](LICENSE) (MPL-2.0)

```bash
git clone https://github.com/nomatronio/nomatron-pack.git
cd nomatron-pack/nomatron
nomad-pack info .
```
